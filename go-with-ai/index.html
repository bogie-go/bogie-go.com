About the book

Ask an AI to build an expense tracker in Go, and it says "Sure!" and hands you two hundred lines of code. It might even run. But can you say what line 40 does? If it breaks next week, where would you start looking?

This book teaches you Go with an AI assistant at your side from the first page, without letting it think for you. Every chapter follows one simple loop, the SURE loop: Specify what "done" means, Use the AI, Review the code, and Explain it in your own words. The one rule: be SURE you can explain it.

You'll build Tracker, a small expense tracker that grows from a one-line program into a tested, concurrent web API, using only Go's standard library. Along the way, the AI's job grows from tutor to pair to implementer, and your judgment grows with it.

What you'll learn

  • Write the tests that say what "done" means, then let the AI build to them
  • Check AI-written Go with the compiler, go vet, your tests and the race detector
  • Spot where AI gets Go wrong: outdated advice, money in float64, ignored errors and data races
  • Learn Go's core ideas well enough to explain them: slices, maps, structs, errors, packages, interfaces, HTTP and goroutines

Frequently asked questions

Is Go good for beginners?

Yes. Go is a small language with a short list of keywords and one loop keyword, so there's less to learn before you build something real. Its compiler gives clear error messages, and the tools you need come with it: go test for tests, gofmt for formatting and go vet for common mistakes. This book uses only Go's standard library, so there's no framework to learn first.

Can I learn Go with AI?

Yes, if the AI helps you think instead of thinking for you. Every chapter of Go with AI uses the SURE loop: Specify what “done” means, Use the AI, Review the code, and Explain it in your own words. The AI starts as your tutor, becomes your pair and ends as the implementer, while you write the tests and review its code.

Is the Go with AI book free?

It's free to read online: the whole book is on this site, with every chapter and appendix on its own page. The ebook costs $0.99 (Kindle, or PDF and EPUB on Leanpub) and the paperback $9.99; both are coming soon.

What do I need installed?

A computer running macOS, Windows or Linux, and an internet connection. You install Go 1.27 (Chapter 1 shows how), an editor such as Visual Studio Code with the Go extension, an AI coding assistant (the examples use Claude Code, but any assistant works) and Git. Appendix A walks through the setup.

Do I need programming experience?

No. You don't need to know Go. If you've written a little code in another language, that helps, but the book walks you through every step, starting with installing Go. It's written for junior developers and anyone newer to programming.

What will I build?

Tracker, a small expense tracker. It starts as a one-line program and grows into a tested, concurrent web API organized into packages, using only Go's standard library, with no framework and no database server.

Where are the answers to the practice exercises?

On the practice answers page: worked answers to the optional Practice exercise at the end of Chapters 1 to 7, each run on Go 1.27.4.
