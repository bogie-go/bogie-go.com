Learn Go with Human Mind and Assisted AI

The AI always says "Sure!" Are you sure? This short book teaches Go to new developers with an AI assistant at your side from page one, and one simple loop, the SURE loop (Specify, Use the AI, Review, Explain), so you never keep code you can't explain.

    Who it's for

    Junior developers and newcomers who are learning to code with AI. You don't need any Go, and the code uses only Go's standard library: no framework and no database server. Over seven short chapters you'll build an expense tracker, a command-line tool that grows into a small web API, with Claude Code in the examples. The SURE loop and the prompts work with any assistant.
