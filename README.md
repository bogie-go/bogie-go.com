# bogie-go.com

The website for [Bogie](https://github.com/bogie-go/bogie), served by GitHub
Pages from this repository's `main` branch. Plain HTML, nothing built, nothing
fetched from elsewhere: `index.html`, the mascot, a favicon, and the `CNAME`
that points the custom domain here.

Edit `index.html`, push, and Pages publishes it.
